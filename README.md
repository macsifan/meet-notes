# Meet Notes

Локальный AI note taker для Google Meet: записывает встречу, расшифровывает её и
собирает заметку с решениями и задачами — кто что взял на себя и к какому сроку.

Аудио не покидает ваш компьютер: расшифровка идёт локальным whisper.cpp.
Наружу уходит только текст транскрипта: выжимку делает Claude Code по вашей
подписке, отдельный API-ключ не нужен.

## Как это работает

```
Chrome-расширение ──чанки по 5 с──> localhost:8788 ──> ffmpeg ──> whisper.cpp
        │                                                              │
        └── лог активного говорящего из DOM Meet ──> сшивка по времени ─┘
                                                             │
                                          claude -p ──> data/notes/*.md
```

Whisper не различает голоса, поэтому имена берутся из двух мест:

- **ваш голос** — по каналу: расширение пишет микрофон в левый канал стерео,
  собеседников в правый, и слова из левого канала подписываются вашим именем;
- **собеседники** — из самой встречи: расширение следит, чья плитка «говорит»,
  и пишет лог смен говорящего.

Whisper выдаёт таймкод каждого слова, поэтому фраза режется ровно на смене
говорящего, даже если люди перебрасываются короткими репликами.

## Качество распознавания

- **Язык** выбирается в окне расширения (по умолчанию русский). Автоопределение
  смотрит только на первые 30 секунд и может ошибиться на «hello, can you hear me».
- **Глоссарий** `data/glossary.txt`: термины по одному на строку. Вместе с именами
  участников и названием встречи они уходят Whisper как подсказка, и он
  перестаёт коверкать «АБ-тест», «MDE», названия продуктов. Выжимка тоже
  получает глоссарий и пишет термины правильно.
- **Замер**: `scripts/eval.mjs` режет фрагменты встреч, вы вычитываете эталон,
  и любое изменение (модель, подсказка, каналы) сравнивается в цифрах:

  ```bash
  node scripts/eval.mjs cut <id записи> --from 600 --to 900 --name планирование
  cp data/eval/планирование/draft.txt data/eval/планирование/reference.txt  # и вычитать
  node scripts/eval.mjs run --label база
  node scripts/eval.mjs run --label без-подсказки --no-prompt
  ```

## Установка

### Что нужно

| | Зачем |
|---|---|
| Mac на Apple Silicon | скрипты рассчитаны на macOS (Homebrew, launchd); на Intel работает, но распознавание в разы медленнее |
| Google Chrome | расширение пишет звук вкладки Meet |
| [Homebrew](https://brew.sh) | через него ставятся ffmpeg и whisper.cpp |
| Node.js 20 или новее | сервер и пайплайн; `brew install node` |
| [Claude Code](https://claude.com/claude-code) с выполненным входом | делает выжимку; нужна подписка, в которой доступна модель Opus |
| ~2 ГБ на диске | модель распознавания; записи встреч занимают ещё десятки мегабайт каждая |

### Что не нужно

- **API-ключ Anthropic.** Выжимка идёт через `claude -p` по вашей подписке.
- **Python, Docker, видеокарта.** whisper.cpp сам использует Metal на Apple Silicon.
- **`npm install`.** Он ставит только jsdom для тестов, серверу и расширению зависимости не нужны.
- **Публикация расширения в Chrome Web Store.** Оно грузится из папки в режиме разработчика.
- **Глоссарий и автозапуск.** Оба необязательны, без них всё работает.

### Шаги

1. Скачать проект:

   ```bash
   git clone https://github.com/macsifan/meet-notes.git
   cd meet-notes
   ```

2. Поставить инструменты и модели. Скрипт проверит Homebrew и Claude Code,
   поставит ffmpeg и whisper.cpp, скачает модель распознавания (~1.6 ГБ)
   и модель тишины (~1 МБ). Повторный запуск безопасен: готовое пропускается.

   ```bash
   bash scripts/setup.sh
   ```

3. Запустить сервер заметок. Выберите один вариант:

   ```bash
   npm run server                        # в отдельном окне терминала, пока он открыт
   bash scripts/install-autostart.sh     # сам поднимается при входе в систему
   ```

   Проверка: <http://127.0.0.1:8788/> открывает страницу «Заметки встреч».

4. Установить расширение:
   1. Открыть `chrome://extensions` и включить «Режим разработчика» (справа вверху).
   2. Нажать «Загрузить распакованное расширение» и выбрать папку `extension/`.
   3. Открыть страницу настроек расширения и нажать **«Разрешить микрофон»**.
      Это обязательный шаг: во время встречи запросить доступ уже нельзя,
      и без него в записи будут слышны только собеседники.
   4. Там же нажать «Проверить сервер».

5. Необязательно: вписать в `data/glossary.txt` названия своих продуктов,
   команд и термины, по одному на строку. Так Whisper перестанет их коверкать.

### Обновление

```bash
git pull
bash scripts/setup.sh                                   # если появились новые модели
launchctl kickstart -k gui/$(id -u)/com.meetnotes.server  # или перезапустить npm run server
```

После этого в `chrome://extensions` нажать «Обновить» на карточке расширения.

### Удаление

```bash
bash scripts/install-autostart.sh --remove
```

Затем удалить расширение в `chrome://extensions` и папку проекта. Записи
и заметки лежат внутри неё, в `data/`, поэтому удалятся вместе с ней.

### Если что-то не так

- **В окне расширения «Сервер заметок не запущен».** Не запущен шаг 3.
  Логи автозапуска лежат в `~/Library/Logs/meet-notes.log`.
- **Слышно только собеседников.** Не выдан доступ к микрофону, шаг 4.3.
- **Заметка не появилась.** Проверьте, что `claude` в терминале отвечает и вход
  выполнен. Запись не пропадёт: сервер подхватит её при следующем запуске.
- **Записи короче 15 секунд** намеренно пропускаются.

### Для разработки

```bash
npm install && npm test
```

## Использование

1. Зайти во встречу.
2. Нажать иконку расширения — запись начнётся сама (галочка «Начинать запись
   автоматически» включена по умолчанию).
3. Когда выйдете из встречи, запись остановится и уйдёт в обработку сама.
4. Через несколько минут заметка появится на <http://127.0.0.1:8788/>
   и в папке `data/notes/`.

Часовая встреча обрабатывается примерно за 5 минут на Apple Silicon.

### Почему всё же нужен один клик

Chrome разрешает захват вкладки только после жеста пользователя — полностью
автоматический старт по входу во встречу браузер отклоняет. Расширение сначала
пытается запуститься само, и если Chrome отказал, зажигает на иконке синюю
метку `▶`: клик по ней сразу начинает запись, ничего больше нажимать не нужно.

Индикатора записи внутри Meet намеренно нет — он попал бы в кадр при
демонстрации экрана. Состояние видно только по бейджу `REC` на иконке.

## Что внутри заметки

Название, дата, участники, краткое содержание, а дальше — решения, задачи,
открытые вопросы, риски и полный транскрипт под спойлером.

Каждая задача сопровождается дословной цитатой, на которой она основана:

```markdown
## Задачи

- **Мария** — Настроить нагрузочный стенд · к пятнице
  > «Я возьму на себя настройку нагрузочного стенда и сделаю её к пятнице»
```

Цитата — не украшение: по ней видно, что задача действительно прозвучала,
а не была домыслена моделью.

### Разбор: как я общаюсь

Перед транскриптом идёт свёрнутый блок о том, как общался владелец записи.
Он свёрнут, чтобы не попасть в кадр, если заметку показывают на демонстрации.

- **цифры** считаются по транскрипту, без модели: доля эфира против ровной,
  число ходов и самый длинный монолог, темп, сколько задано вопросов, сколько
  реплик начато поверх собеседника, слова-паразиты на 100 слов;
- **советы** даёт Claude: что получается, что поправить и как сказать иначе,
  каждый пункт с дословной цитатой, плюс одно упражнение на следующую встречу.

Если владелец сказал меньше 40 слов, блока нет. Если модель не ответила,
остаются одни цифры. Цифры зависят от подписей говорящих: без раздельных
каналов микрофона и вкладки доля эфира может врать.

## Если имена говорящих не определяются

Вёрстка Meet обфусцирована и меняется. Детект намеренно не завязан на имена
классов — он ловит плитку, которая активнее всех мутирует во время речи, — но
привязка к плиткам участников всё же нужна.

Когда имена перестанут определяться, в консоли вкладки Meet:

```js
const { createTracker } = await import(chrome.runtime.getURL('speaker-detect.js'));
createTracker().dumpTiles();
```

Команда покажет, что расширение видит на плитках. Дальше правится один объект
`SELECTORS` в `extension/speaker-detect.js`.

Даже если детект отвалится полностью, запись и выжимка продолжат работать:
ваши реплики всё равно подпишутся по каналу микрофона, а реплики собеседников
останутся без имён (во встрече вдвоём имя собеседника подставится само).

## Структура

| Папка | Что делает |
|---|---|
| `extension/` | запись звука и сбор метаданных встречи |
| `server/` | приём чанков, очередь обработки, просмотр заметок |
| `pipeline/` | аудио → транскрипт → выжимка → markdown |
| `data/notes/` | готовые заметки |
| `data/recordings/` | исходные записи и метаданные |
| `data/glossary.txt` | термины для распознавания и выжимки |
| `data/eval/` | фрагменты с эталонами и результаты замеров |

Пайплайн не знает про браузер и запускается на любом аудиофайле:

```bash
node pipeline/run.mjs запись.m4a метаданные.json
```

## Правовая сторона

Расширение никого не уведомляет о записи — ни сообщением в чат, ни индикатором
в интерфейсе встречи. Во многих юрисдикциях уведомление участников обязательно,
поэтому ответственность за то, кого и как предупредить, лежит на владельце
установки.
